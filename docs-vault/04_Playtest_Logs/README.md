# 04_Playtest_Logs

Thư mục lưu trữ các nhật ký kiểm thử gameplay, giả lập toán học và dữ liệu phân tích:
- Kết quả chạy mô phỏng Monte Carlo (kinh tế game, tỷ lệ rớt đồ, độ cân bằng trang bị).
- Báo cáo Profiler (Async-profiler / Spark / JFR) đo lường tick time (MSPPT - Milliseconds Per Tick).
- Biên bản thử nghiệm tải thực tế (Bot Stress Testing).

## Quy ước đặt tên file
`LOG_{{date:YYYYMMDD}}_{Tên_buổi_test}.md`
